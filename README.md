# Max_website

Download de 3 bestanden en zet ze in dezelfde map. Daarna kan je de index.html dubbel klikken en het opent in je webbrowser. De rest spreekt wel voorzich.

Je kan alle drie de bestanden weer in AI studio zetten om weer met ai verder te gaan. Je kan aan hem vragen om alles in 1 bestand te zetten. Maar ik denk dat dit makkelijker is voor de AI. CSS is voor je de mooi maken van websites. HTML is de hoofd uitlijning enzo en layout. JS is voor de berekeningen en logica.
